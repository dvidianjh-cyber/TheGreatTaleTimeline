# v0.1.2 Bug Fixes & Era Ruler System - Implementation Plan

Addresses the 3 remaining bugs from v0.1.0-bugreport.md and implements the multi-era ruler toggle system.

## Summary of Issues

| Bug | Status | Root Cause |
|-----|--------|-----------|
| **#1** Flyout unclickable | ✅ Fixed | Conflict between wrapper pointer-events and inner panel interaction. |
| **#2** Spline loops | ✅ Fixed | Waypoint sorting and monotonic Hermite interpolation. |
| **#3** Event vanishes on hover | ✅ Fixed | Scaling the node changed hitArea bounds; replaced with fixed hitArea. |
| **#4** Era-specific rulers | ✅ Fixed | Added stacked ruler rows togglable per-era. |

## Proposed Changes

### Bug #1 — Flyout Panel Cannot Be Interacted With
- **Fix**: Removed `pointer-events: none` from the ID selector and handled it via classes. Added propagation stopping in `FlyoutPanel.js`.

### Bug #3 — Event Node Vanishes on Hover
- **Fix**: Set a fixed `hitArea` (Rectangle/Circle) on the container so that `gfx` scaling doesn't affect hit detection. Animated scale via GSAP.

### Bug #4 — Era-Specific Ruler System
- **Revert**: Reverted the previous "epoch-relative main ruler" change.
- **Feature**: Added a new `ruler` object to the epoch schema. Updated `RulerRenderer` to support stacked rows and `TemporalEngine` to compute era-relative ticks.
