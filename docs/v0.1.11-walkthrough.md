# v0.1.11 Walkthrough: Measure Tool Enhancements

## Overview
This update fundamentally overhauls the Measure Tool to support a much requested feature: the ability to draw and persist **multiple independent measurements** on the timeline simultaneously. In addition, critical UI bugs involving tooltip positioning and CSS styling have been resolved.

## What's Changed
1. **Multiple Concurrent Measurements:**
   - The engine now manages an array of measurement objects (each containing a Pixi `Graphics` line and an HTML tooltip card).
   - You can draw as many lines as needed. Once a line is fully drawn (second click), its tooltip locks in place and remains fixed on the canvas.
2. **State Persistence:**
   - Untoggling the Measure Tool (turning it off) now safely reverts your cursor and disables drawing, without silently wiping your existing measurements.
3. **Clear Measurements Control:**
   - A dedicated "trash" icon now sits directly adjacent to the ruler icon in the toolbar. Clicking it acts as a global wipe, instantly destroying all drawn measurement lines and unmounting their tooltip cards from the DOM.
4. **Tooltip Rendering Fixes:**
   - The tooltip data card coordinates are now accurately calculated against the canvas container's bounding box, preventing them from rendering off-screen.
   - Text styling within the tooltips now accurately hooks into the application's defined typographic system (`.tooltip-date-baseline` and `.tooltip-date-era`).

## Validation
* Draw multiple measurements across the timeline and ensure they do not overwrite each other.
* Ensure tooltips lock precisely adjacent to the measurement endpoint.
* Toggle the tool on and off to confirm lines persist.
* Click the trash icon to verify a clean wipe of all measurement objects.
