# Parchment Theme Implementation

## Changes Made
1. **Parchment Texture & Color Palette:** Implemented a new parchment paper background (`assets/parchment-bg.png`) and updated the central CSS variables in `main.css` to use a light-themed ink/parchment palette (`--bg-primary: #f4ecdf` and `--text-primary: #2c251c`).
2. **Typography Update:** Integrated Google Fonts `Kalam` and `Caveat` for a hand-written body and label styling, paired with `Cinzel Decorative` for an ancient look on titles.
3. **Canvas Renderers Theme Implementation:**
   - **`BiographicalRenderer` and `LaneRenderer`**: Updated stroke colors, label fill colors, and typography to seamlessly blend the PixiJS canvas with the DOM-based UI.
   - **`CanvasManager`**: Adjusted the epoch background colors to use lighter tones with a parchment-matching default.
   - **`EventNodeRenderer`**: Modified event node strokes and labels to utilize the high-contrast ink color and the new `Kalam` font.
   - **`PrologueRenderer` and `LoDClusterEngine`**: Updated the dark "void" base colors to parchment hues and updated text styling.
   - **`SampleData.js`**: Replaced dark epoch and lane `color_hint` values with lighter pastel equivalents so the embedded sample data matches the new aesthetic.

## Note on Testing
If you notice that the map lanes or epochs still have dark backgrounds, this is likely because the timeline has previously cached the old `SampleData` into your browser's IndexedDB. You can force an update by either re-importing the dataset, clearing your browser's site data for `localhost:3000`, or triggering a reset from the Import/Export UI.

Once you have verified the visual changes, we can proceed to address the time ruler accuracy scaling and the flyout panel bugs.
