# v0.1.11 Implementation Plan (Revised)

## Goal
Resolve bugs related to the Measuring Tool's tooltip UI, fix state loss upon tool deactivation, implement a dedicated "Clear Measurements" UI button, and **refactor the tool to support multiple persistent measurements on the canvas simultaneously**.

## User Review Required
The new requirement to support **multiple concurrent measurements** changes the internal data structure of `MeasureTool.js`. It will no longer manage a single `this.graphic` and `this.tooltip`, but rather a collection of them. Please review the updated proposed changes.

## Proposed Changes

### 1. Refactor MeasureTool for Multiple Concurrent Measurements & Tooltip Fixes
**Component:** `js/canvas/MeasureTool.js`
*   **State Array:** Instead of a single `this.graphic` and `this.tooltip`, the `MeasureTool` class will maintain a `this.measurements = []` array.
*   **Click 1 (Start Draw):** When the user clicks to start, we will instantiate a new PixiJS `Graphics` object and a new HTML tooltip `div`. Both will be appended to their respective layers/containers and pushed as an object to `this.measurements`.
*   **Pointer Move (Drawing):** The mouse move event will only update the *latest* measurement in the array. The tooltip's position will be strictly calculated using the canvas container's `rect.left` and `rect.top` bounding box to ensure it renders at the correct coordinates on the screen.
*   **Click 2 (Finish Draw):** When the user finishes the line, the `status` will revert to `idle` (ready to draw a new one), but the completed measurement will remain in the array. Since the mouse move no longer updates this measurement, its tooltip will remain fixed at its last drawn location.
*   **CSS Class Correction:** The generated HTML for tooltips will correctly use `.tooltip-date-baseline` and `.tooltip-date-era` styles to match the app aesthetics.

### 2. State Persistence
**Component:** `js/canvas/CanvasManager.js`
*   **Decouple Visibility:** Modify the `Events.MEASURE_TOGGLED` event listener. Toggling the tool off will revert the cursor style and prevent new drawings, but will **no longer** invoke `measureTool.clear()`.

### 3. Clear Measurements Control
**Component:** `js/ui/PanelController.js` & `js/canvas/MeasureTool.js`
*   **UI Addition:** Update `_buildToolbar()` to include a `<button class="toolbar-btn" id="btn-measure-clear" title="Clear Measurements"><i data-lucide="trash-2"></i></button>` directly adjacent to the existing `#btn-measure`.
*   **Event Binding:** Add a click listener for `#btn-measure-clear` that invokes `measureTool.clear()`.
*   **Clear Logic:** `measureTool.clear()` will be updated to iterate through `this.measurements`, destroying all Pixi graphics and removing all DOM tooltips from the screen, then resetting the array.

## Verification Plan
1. Draw a measurement, finish it, and verify the tooltip card locks in place adjacent to the cursor's last location.
2. Draw a *second* measurement and verify both the first and second measurements remain visible simultaneously.
3. Toggle off the measuring tool and verify all drawn lines and tooltips remain visible on the canvas.
4. Click the new "Clear Measurements" trash icon and verify the canvas and all tooltips are cleared instantly.
