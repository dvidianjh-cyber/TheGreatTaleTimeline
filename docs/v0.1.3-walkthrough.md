# v0.1.3 Walkthrough: Unified Stable Coordinates

I have successfully stabilized the timeline coordinate system, resolving the "drifting" rulers and "vanishing" nodes reported.

## Key Changes

### 1. Stable World Scale
The `pixelsPerTU` calculation is no longer dependent on the window width. 
- **Previous**: `pptu = width / 34000 * zoom` (Drifts on resize)
- **Current**: `pptu = 0.05 * zoom` (Absolute stability)

### 2. Sticky Lane Labels
Lane labels now stay pinned to the left edge of the screen as you pan, using a counter-panning calculation relative to the world container.

### 3. Pixel-Perfect Ruler Sync
The DOM-based ruler rows and the PixiJS canvas now share the exact same projection formula.
```javascript
screenX = (worldTU * pptu) + panOffsetX;
```
