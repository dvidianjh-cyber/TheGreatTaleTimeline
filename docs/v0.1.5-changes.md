The Time Units definition should not need to be too difficult - you MUST have at least 1 time_system, designated the 'primary', which means that it is used as the 'true units' (and can be referenced with the abreviation 'TU', as well as it's own time system) for internal conversions. Any other time_system simply needs a 'conversion_factor'. 
[
    { id: "solar", name: "Solar Year", abbreviation: "SY", isPrimary:true },
    { id: "valian", name: "Valian Year", abbreviation: "VY", conversion_factor: 9.582 }
]
The epochs are then defined with start and end dates in the 'primary' time_system (with abreviation 'TU' OR whatever abreviation is defined in the data), define which time-system to use for the 'epoch date units', as well as define it's own 'epoch Date abreviation' (making another 'unit').

{
    id: "lamps",
    label: "Years of the Lamps",
    start_tu: 1,
    end_tu: 33537,
    time_system: "valian",
    abbreviation: "YL",
    color: "#e6def4",
}
(The epoch definition should not need the 'conversion_factor' if it references a time_system)

The 'rulers' should then be defined entirely seperately - the 'primary' ruler which is always shown will just be that time_system's abbreviation. then the other rulers are linked to an epoch (which already defines the start, end and time units):
//inside world_config:

        label: "Lamps Year (Valian)",
