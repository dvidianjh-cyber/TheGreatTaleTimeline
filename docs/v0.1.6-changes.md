# Change Request — v0.1.6 UI & Tooling Upgrades

This document outlines the requested layout changes, bug fixes, and feature enhancements for the Timeline application, focusing on viewport controls, data management, and tooltip structures.

---

## 1. Canvas & Viewport Controls

### Zoom Slider Calibration
* **Issue:** The horizontal zoom slider reaches maximum zoom at approximately 60% of the track.
* **Requirement:** Recalibrate the scale so the far-right edge of the slider represents the absolute maximum zoom level (1 TU spanning the entire viewport width).

### Floating Viewport Controls
* **Issue:** Zoom scroll bars currently sit in the main title bar, detached from the canvas context.
* **Requirement:** Move the horizontal and vertical zoom sliders to float directly over the top-left corner of the canvas/grid.
* **Layout Details:** * Place the horizontal scroll bar at the top-left of the canvas area (just under the Era Rulers).
  * Place the vertical scroll bar anchored to the top-left vertical edge of the canvas. *(See reference image `image_1c393c.jpg`)*

---

## 2. 'Edit World Data' Dialog Redesign

### Modal Header & Navigation
* **Header Bar Actions:** Relocate the "Load Data" and "Save Data" functions/icons from the main application header into the header of this modal.
* **World Name Input:** Add a text input box to the header bar (before the navigation tabs) to view and edit the master World Name.
* **Tabbed Interface:** Implement top-level tabs for: `Lanes`, `Entities`, `Events`, and `Time/Epochs`.

### Layout & Form Styling
* **Split-Pane Layout:** Design a Master/Detail layout where the left pane contains the selectable List of Items, and the right pane displays the Edit Form.
* **Form Field Alignment:** Transition away from full-width input controls. Place labels and their corresponding input controls on the same horizontal row to save vertical space.
* **Color Selection:** Replace standard text inputs for `color_hint` fields with a color picker control. It must feature a quick-select palette of ~16 preset "primary" colors.

### Configuration Tab (Time/Epochs)
* **Requirement:** The new configuration tab must allow users to set and edit `time_systems`, `epochs`, and `rulers`. 
* **Design Note:** Because these three datasets are highly interconnected, the UI controls should be logically composed to reflect their dependencies.

---

## 3. Visibility Fly-out Panel Enhancements

### Element Reordering
* **Era Rulers:** Move the era ruler toggles to the very top of the fly-out panel.
* **Search Box:** Reposition the "Search Entities" input so it sits immediately above the Entity Checkboxes list.

### Functional Additions
* **Entity Group Toggles:** Add master toggle switches to the entity list to allow users to show/hide an entire "group" of entities with a single click.
* **Slider Improvements:** Group the 'Font Size' and 'Importance' sliders together visually. Update their CSS to make the slider "rail/track" much more visible to the user.

---

## 4. Event Tooltip Card Restructure

### Layout Redesign
* **Requirement:** Re-arrange the hover card into a 2-column grid layout (approximately 75% left / 25% right).

### Column Content
* **Left Column (75%):** * Event Title (keep existing styling)
  * Importance Stars
  * Description body
* **Right Column (25%):**
  * Category Pill
  * Date List
  * Participants Pills (rendered as a vertical stack)

### Typography
* **Requirement:** Standardize the date styles. The absolute "Solar Year" (or base TU) date must share the same visual style and font sizing as the relative epoch date units.
