# v0.1.12 Implementation Plan

## Goal
Fix the missing `measure-tooltip-card` CSS class and fundamentally overhaul the Measure Tool so that drawn measurements are anchored to the world timeline data (Time Units) rather than static screen coordinates. This ensures measurement lines properly scale and translate when the user pans and zooms the canvas.

## Open Questions
None. The required architectural changes are clear.

## Proposed Changes

### 1. Fix Tooltip CSS
**Component:** `css/main.css`
*   **CSS Class Addition:** The `.measure-tooltip-card` class is entirely missing from the stylesheet. I will add it, utilizing the existing tooltip design tokens (glassmorphism background, border radius, padding, `z-index: 400`, `pointer-events: none`, `position: absolute`).

### 2. Map Measurements to World Data (TU)
**Component:** `js/canvas/MeasureTool.js`
*   **Data Structure Update:** Instead of storing `startX` and `endX` pixel coordinates, the measurement objects in `this.measurements` will store `startTu`, `endTu`, and the static `screenY` anchor point.
*   **Coordinate Projection:** I will implement a `renderAll()` method that iterates through the measurements array. For each measurement, it will recalculate the `startX` and `endX` screen pixels on the fly using `(tu * state.pixelsPerTU) + state.panOffset.x`.
*   **Event Listener:** The `MeasureTool` constructor will bind to `bus.on(Events.RENDER_DIRTY, () => this.renderAll())`. This ensures that whenever the user pans or zooms (which triggers a dirty render in the engine), the measurement lines and their HTML tooltips will perfectly track their anchored positions on the timeline.
*   **Update Drawing Logic:** During the active `drawing` state, the mouse movement will dynamically update the `endTu` of the active measurement and instantly call `renderAll()`.

## Verification Plan
1. Draw a measurement on the canvas.
2. Verify the HTML tooltip card renders successfully with proper styling.
3. Pan the timeline left and right. Verify the drawn line and tooltip move synchronously with the timeline events.
4. Zoom in and out. Verify the drawn line scales proportionally to the time units it measures, while the tooltip maintains its correct position at the endpoint.
