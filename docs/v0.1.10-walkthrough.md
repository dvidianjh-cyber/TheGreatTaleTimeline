# v0.1.10 Walkthrough & Test Report

I have implemented the bug fixes and features specified in the v0.1.10 Bug Report.

## 1. Measure Tool Refactoring
*   **2-Click Interaction System:** Re-wrote `MeasureTool.js` to eliminate dragging. The tool now operates via a simple `idle` -> `drawing` -> `finished` state machine.
*   **HTML Tooltip Card:** Removed the old PixiJS text label and replaced it with a DOM-based `.measure-tooltip-card` that seamlessly matches the aesthetics of the standard event tooltip card.
*   **Multi-system Time Display:** The new HTML tooltip renders all active epoch rulers sequentially based on the `tuDiff`.
*   **Persistent Rendering:** The measured line and tooltip remain visible until the tool is cleared.
*   **Cursor Override:** Implemented logic within `CanvasManager.js` to change the pointer to `crosshair` across the canvas area whenever the Measure Tool is toggled on.
*   **UI Clarity:** Added an inset shadow (`box-shadow: inset 0 2px 4px rgba(0, 0, 0, 0.2), var(--shadow-glow);`) to active buttons in `main.css`, ensuring the toggled state of the Measure Tool is obvious.

## 2. Empty Default State
*   **Zero-State Initialization:** Updated `app.js` to automatically inject an empty, standard dataset when no data is detected in `IndexedDB`. The application will no longer fallback to rendering hardcoded demo data upon boot.
*   The fallback dataset has been retained, but is now explicitly invoked only via the "Load Sample..." dropdown within the Data Editor modal.

## 3. Data Editor Enhancements
*   **New World Option:** A `New` button has been added to the header of the `DataEditorModal`. When clicked, it purges all current lists in the editor and instantiates an empty slate.
*   **World Settings Tab:** Introduced a new `World Settings` navigation tab in the editor.
    *   This maps to the root `world_config` JSON tree, allowing users to modify the World Name, Default View Mode, and Default Visible Timespan in the UI without modifying raw JSON.
    *   `SchemaValidator.js` has been updated to recognize the new schema payload formats.

## 4. UI/Typography Fixes
*   Reduced the font sizes of `.tooltip-date-baseline` and `.tooltip-date-era` in `main.css` to 12px, perfectly matching the 12px baseline of `.tooltip-description`.

## Verification Instructions
1.  **Test the Measure Tool:** Click the ruler icon. Observe the active state and cursor override. Click anywhere on the canvas to set origin, move mouse to preview strictly horizontal line and tooltip, click again to finalize.
2.  **Test the Editor:** Press `Edit Data`. Observe the new `World Settings` tab and verify you can input custom parameters. Click the `New` button to instantiate a blank slate.
3.  **Test the Tooltip:** Hover over any node and verify the date fonts are matched correctly to the body text.
