# The Great Tale Timeline - Project Summary (v0.1.10)

## Overview
**The Great Tale Timeline** is a high-performance, web-based chronological engine designed for visualizing complex historical and fictional narratives across vast temporal scales. Built with a focus on deep lore (initially demonstrated via a Tolkien/Arda dataset), it allows users to navigate extensive histories using interactive, visually rich timelines.

## Core Architecture
The application leverages a modular, reactive architecture running fully in the browser:
- **EventBus & StateManager**: A custom pub/sub system and reactive state management for UI and canvas updates.
- **TemporalEngine**: A robust date math system that supports multiple temporal systems (e.g., Solar, Valian) and relative epoch units (e.g., First Age, Second Age).
- **PixiJS 8 Canvas Engine**: High-performance WebGL layered rendering for complex visual elements (epochs, lanes, splines, events, UI overlay).
- **IndexedDB Persistence**: Local storage using Dexie.js for auto-saving, debounced writes, and data recovery.
- **Vanilla web stack**: Standard HTML/CSS/JS module architecture.

## Current Features

### Visual & Interactive Features
- **Geographical & Biographical Modes**: Two distinct visualization modes. Geographical places events in horizontal spatial lanes, while Biographical provides a Gantt-chart style lifespan view of entities.
- **Zoom & Pan Engine**: Smooth mouse-wheel zoom with GSAP interpolation and cursor-anchored zooming, alongside click-and-drag panning.
- **Elastic Ruler**: A dynamic, DOM-based time ruler that adapts to the current zoom level and displays nested, colored epoch bands.
- **Event Nodes & Tooltips**: Events are rendered as points or range bars depending on their duration, colored by type, and sized by importance. Clicking events opens interactive, glassmorphism-styled tooltips detailing participants, importance, and relative dates.
- **Entity Splines**: Character paths are visualized using Bézier curves moving across geographic lanes, color-coded by entity.
- **Temporal Fuzziness**: Events with approximate dates are rendered with a distinct blur/mist effect.
- **Level of Detail (LoD) Clustering**: Uses spatial grid bucketing to cluster dense events when zoomed out.

### Data & Content Management
- **Relative Date Lifespans**: Entities can be defined using relative epoch units (e.g., FA, SA, TA) instead of strict absolute values, improving data entry and lore accuracy.
- **Reactive Data Editor**: A modal interface for modifying events, entities, and lifespans directly within the application.
- **Import/Export**: Drag-and-drop JSON upload with schema validation, plus the ability to export the current timeline back to JSON.
- **Flyout Filter Panel**: A high-density control matrix to toggle lanes, filter entities by race, adjust importance thresholds, and use a search function.
