# v0.1.10 Implementation Plan

This plan addresses the bugs and feature requests specified in the `v0.1.10-bug-report.md`.

## Proposed Changes

### Measure Tool Refactor & Fixes

#### [MODIFY] js/canvas/MeasureTool.js
*   **2-Click Interaction Model:** Remove drag logic. State machine: `idle` -> `drawing` -> `finished`.
    *   **Click 1:** Begins drawing. Records `startX` and recalculates `startY` using `canvasContainer.getBoundingClientRect().top` to fix the Y-offset bug.
    *   **Mousemove:** Updates `endX`. The Y coordinate is locked to `startY` for a strict horizontal line.
    *   **Click 2:** Commits the line and transitions to `finished`. The line and tooltip persist.
*   **HTML Tooltip Card:** Remove the PixiJS `Text` label. Create an absolute positioned HTML `div` element matching the glassmorphism style of the event tooltip card.
    *   Track it to the right of the cursor during movement.
    *   Use `temporalEngine` to convert the `tuDiff` into all currently active epoch rulers (read from `state.activeEpochRulers` and baseline 'solar').
*   **Cursor Override:** Set the cursor style on the canvas container to `crosshair !important` when the tool is activated, and restore it when deactivated.

#### [MODIFY] js/ui/PanelController.js
*   **Active State:** Ensure the measure button (`#btn-measure`) toggles appropriately.
*   Update the `bus.emit(Events.MEASURE_TOGGLED)` listener to trigger cursor overrides in the Canvas Manager.

#### [MODIFY] css/main.css
*   **Toolbar Active State:** Enhance `.toolbar-btn--active` to make the toggled state explicitly obvious (e.g., adding an inset shadow `box-shadow: inset 0 2px 4px rgba(0,0,0,0.2), var(--shadow-glow);` or a distinct background).
*   **Measure Tooltip Card:** Add CSS rules for the new HTML measure tooltip (e.g., `.measure-tooltip-card`).
*   **Event Tooltip Typography:** Update `.tooltip-date-baseline` and `.tooltip-date-era` to match `.tooltip-description` (`font-size: calc(12px * var(--base-font-size));`).

### Empty Default State Logic

#### [MODIFY] js/app.js
*   If IndexedDB is empty, initialize a completely blank default schema (empty lanes, entities, events, basic world_config) instead of leaving it null or showing an uninitialized application state.
*   Remove fallback to sample data. Sample data will only be available via the editor modal's "Load Sample" option.

#### [MODIFY] js/canvas/CanvasManager.js
*   When parsing the loaded configuration, read `default_mode` to set the initial view mode (geographic/biographical), and use `default_visible_timespan` to set the initial zoom and pan parameters instead of standard auto-fitting, if provided.

### Data Editor & Extensibility Enhancements

#### [MODIFY] js/ui/DataEditorModal.js
*   **"New World" Button:** Add a `#edit-btn-new` button next to "Import/Export". Clicking it resets `this.editData` to an empty state with a default `world_config`.
*   **"World Settings" Tab:**
    *   Add a new tab button `<button class="edit-tab-btn" data-domain="world_config">World Settings</button>`.
    *   In `renderForm()`, add input fields for `world_name`, `default_mode` (Select: Geographic/Biographical), and `default_visible_timespan` (two number inputs for Start TU and End TU).

#### [MODIFY] js/core/SchemaValidator.js
*   Update `validateWorldConfig` to accept `default_visible_timespan` (Array of two numbers) and `default_mode` (String).

#### [MODIFY] js/data/SampleData.js & data/sampleData_arda.json
*   Update the sample Arda dataset to include:
    ```json
    "default_visible_timespan": [0, 5000],
    "default_mode": "geographic"
    ```

## Verification Plan

### Automated/Manual Tests
*   **Measure Tool:** Activate tool, verify cursor changes to crosshair. Click once, move mouse horizontally, verify horizontal line and multi-unit HTML tooltip follows cursor correctly. Click again, verify line and tooltip persist.
*   **Empty State:** Hard refresh without local data. Verify canvas is completely empty without console errors.
*   **Editor New World:** Open Data Editor, click "New World". Verify all grids are cleared.
*   **World Settings:** Switch to World Settings tab, edit `default_mode` and `default_visible_timespan`, save, and verify canvas uses these values upon load.
*   **Typography:** Hover over an event node and verify the date text size matches the description text size.
