# Change Request — Data Editor Fixes & Timeline Tools

This document outlines the required bug fixes for the previously requested UI updates, alongside specifications for a new interactive measurement tool.

---

## 1. 'Edit World Data' Modal Corrections (Bugs)

### Stray Header Buttons
* **Issue:** The 'Import Data' and 'Export Data' buttons are still visible on the main page header bar.
* **Requirement:** Remove these buttons from the main application header completely, ensuring they only appear in the header of the 'Edit World Data' modal as specified in the previous request.

### Tab Layout Implementation
* **Issue:** The modal currently displays a vertical list of tabs.
* **Requirement:** Reposition the navigation tabs to be a horizontal row located in the modal dialog's header pane, positioned next to the new "World Name" text input box.

### Unresponsive List Items
* **Issue:** The Master/Detail list selection is broken. Clicking on a row in the left-hand list does not load or display the record's form on the right-hand pane. This bug affects all tabs.
* **Requirement:** Bind the click events on the list items so that selecting a record dynamically populates the adjacent form with the correct data for editing.

### Missing Time/Epoch Data
* **Issue:** The new 'Time/Epochs' configuration tab is completely blank and not displaying any data.
* **Requirement:** Implement the lists and forms required to configure `time_systems`, `epochs`, and `rulers` data within this tab, as originally requested.

### Primary Time Ruler Visibility
* **Requirement:** Make the visibility of the "Primary Time Ruler" optional.
* **UI Integration:** Add a specific toggle for the primary ruler within the visibility options fly-out panel, matching the behavior and styling of the other era ruler toggles.

## 2. Interactive Time Measure Tool
* **Requirement:** Introduce a new "Time Measure" tool to calculate spans across the timeline.
* **Interaction Flow:**
  1. **Activation:** User activates the tool, changing the cursor to a cross-hair.
  2. **Start Point:** User clicks once to set the starting point.
  3. **Measuring:** As the user moves the mouse, a dynamic line is drawn from the start point to the cursor, accompanied by a tooltip card displaying the real-time time-span calculation.
  4. **Anchor Point:** The user clicks a second time to lock the measurement line and tooltip card in place, making them permanently visible on the canvas.
* **Data Persistence Note:** These measurement markers must only be saved for rendering during the current browser session. Do not append them to the persistent world data or export payload.
